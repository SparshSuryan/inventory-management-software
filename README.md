# Inventory Management Software

A full-stack Inventory Management System developed using:

* React.js
* Node.js
* Express.js
* PostgreSQL
* Prisma ORM

## Project Overview

This application helps businesses manage products, monitor inventory levels, track stock availability, and maintain organized inventory records through a simple and user-friendly interface.

## Features

### Product Management

* Add Product
* View All Products
* View Product Details
* Update Product Information
* Delete Product

### Category Management

* Create Categories
* View Categories
* Organize Products by Category

### Stock Management

* Increase Stock Quantity
* Decrease Stock Quantity
* Prevent Negative Inventory
* Real-time Inventory Updates

### Inventory Monitoring

* Low Stock Detection
* Inventory Status Tracking
* Dashboard Summary
* Total Product Count

### Search & Filter

* Search Products by Name
* Search Products by ID
* Filter Products by Category
* Sort Product Listings

### User Interface

* Responsive Design (Mobile Friendly)
* Dashboard Overview
* Product Management Forms
* Inventory Monitoring Pages

## Technology Stack
